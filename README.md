# PENS — Physics Playground

ブラウザで遊べる3D物理サンドボックスです。ブロック建築、空間に書くペン、物理ガン、ポータル、ミニチュアツール、フレンドリーモブ、ワールドの保存・読み込みに対応。

## 遊び方

Renderで公開されたURLを開き、「世界に入る」を押してください。

| 操作 | アクション |
| --- | --- |
| WASD | 移動 |
| マウス移動 | カメラ回転 |
| Space | ジャンプ |
| 1～5 | ビルダー / ペン / 物理 / ミニチュア / ポータル |
| 左クリック | ツールを使用 |
| Shift + 左クリック (ビルダー) | ブロック削除・ミニ建築回収 |
| E (物理ガン) | 選択ブロックをつかむ / 放す |
| F (物理ガン) | 選択ブロックを飛ばす |
| Q | 物理ボールを発射 |
| Z | 直前の操作を1つ取り消し |
| Esc | マウスロック解除 |

### ミニチュア建築

1. ツール4「MINIATURE」で「通常の1/10サイズになる」を押す。
2. ツール1「BUILD」で小さなブロックを置き、ミニチュア建築を作成する。
3. 別の建築作品にしたいときは「新しいミニ建築を始める」を押す。
4. プレイヤーのサイズを1.00×に戻す。
5. 作品のブロックを Shift + 左クリックで破壊すると、**建築物全体をインベントリの1アイテム**として回収できる。
6. BUILDの「MINI COLLECTION」からその建築物を選んでクリックすると、作品を再配置できる。

### セーブ＆ロード

- 画面右上の **SLOT 1 / 2 / 3** からスロットを選び、**保存**で保存する。
- **ロード**で指定スロットのワールドを復元する。
- **書出 / 読込**でJSONファイルを使ったバックアップと復元が可能。
- ブロック、ペンの線、モブ、ポータル、プレイヤーのサイズ、回収したミニ建築が保存対象。
- スロット保存はブラウザの localStorage を利用します。ブラウザの保存データを削除すると失われるため、長期保存はJSON書き出しを推奨します。
- ワールドの初期化は保存済みスロットを消しません。上書きするには明示的に「保存」を押します。

## 技術構成

- Three.js 0.180.0 (WebGL)
- cannon-es 0.20.0 (3D剛体物理)
- HTML / CSS / JavaScript ES Modules
- 静的サイト。ビルドやサーバー、データベースは不要。

起動は python -m http.server 8080 などのローカルHTTPサーバーで行い、 http://localhost:8080 を開きます。ES Modules のため file:// での直接起動は非推奨です。

## 現在の範囲

シングルプレイヤー用プロトタイプです。ブロックは最大1800個、モブは最大45体まで。建築・物理・簡易ポータル・簡易NPCを実装していますが、複数人オンライン同期、流体、電気回路、複雑な拘束機構は将来の機能です。ゲームライブラリはCDNから読み込むため、初回表示にインターネット接続が必要です。
